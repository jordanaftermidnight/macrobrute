# Additional MicroBrute Modifications — Research Findings

Compiled 2026-04-09 from web research.

---

## New Discoveries (Beyond Existing Documentation)

### 1. Soft Sync Doesn't Work (Design Bug)
- Test points exist for soft sync per schematics
- **Reportedly non-functional** — appears to require a missing capacitor
- Hard sync works fine
- Source: Fwestivus on ModWiggler, confirmed vs Yusynth reference

### 2. Triangle Output Level Problem
- TP124 (triangle) is inherently quieter than other waveform outputs
- No documented fix — suggests dedicated buffer with gain (~2x) needed
- Consider adding gain stage in breakout PCB TL074 (not just unity follower)

### 3. Sine Wave Extraction (Undocumented)
- Triangle shaper test point on VCO can be tapped for approximate sine
- Needs voltage attenuation before use as line-level output
- Worth probing during Phase 0

### 4. Output Protection (Missing in Stock Design)
- Main output has NO protection between opamp and jack socket
- **Tony Allgood fix:** Cut trace between UB5 pin 5 and output socket,
  insert 10kΩ resistor in series
- Prevents opamp damage from shorts or excessive loads
- Already documented in mods_guide.md but flagged as HIGH PRIORITY

### 5. VCA CV Offset Control
- BigCranberry (community) documented adding dedicated offset pot
- Uses TP56 (+5VNUM) and TP11
- Allows fine-tuning VCA CV response — useful for external envelope shaping

### 6. Through-Zero PWM (Experimental)
- Reddit user posted evidence of feasibility per schematics
- Not fully documented — needs further investigation
- Could yield unique tonal characteristics

### 7. Brute Factor CV Control — NOT POSSIBLE
- Confirmed architectural limitation
- Unlike newer Arturia synths, Brute Factor is pure passive feedback path
- Can only be controlled via physical pot or VCA insertion in feedback loop
- Our existing SSI2164-in-feedback-loop design is the correct approach

### 8. MicroBrute UFO Edition = Cosmetic Only
- Black enclosure re-release (2025)
- No hardware changes, no firmware differences
- Same PCB revision as standard model

### 9. MicroBrute SE = Keyboard Version Only
- Discontinued
- No internal hardware differences from standard
- Just different mechanical keyboard

### 10. LFO Rate — NOT Voltage Controllable
- Confirmed: LFO is entirely digital (generated by LPC2361)
- Cannot be voltage-controlled without custom firmware
- Our expander's analog LFO solves this

## Implications for MACROBRUTE Design

| Finding | Action |
|---------|--------|
| Soft sync broken | Test during Phase 0; may need active comparator circuit |
| Triangle quiet | Add 2x gain on TP124 buffer (change feedback R in TL074) |
| Sine extraction | Add as probe point during Phase 0 exploration |
| Output protection | Include in Phase 1 (non-destructive mods) |
| VCA offset | Add to expander CV input conditioning |
| Brute Factor CV | Keep SSI2164 VCA-in-loop design (our approach is correct) |
| UFO = cosmetic | No special considerations needed |
| LFO not VC | Expander analog LFO is essential utility |
