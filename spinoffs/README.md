# MACROBRUTE Spinoffs

Companion projects that grew out of the MACROBRUTE work but are **not part of
the canonical build**. They live here to keep the design history co-located —
graduate either to its own repository if it ever outgrows this folder.

| Spinoff | Status | Description |
|---------|--------|-------------|
| [`jf33-eurorack/`](./jf33-eurorack/) | speculative | DIY Eurorack PT2399 delay (JF-33-style). Bench-built, no PCB yet. |
| [`dso138-desktop/`](./dso138-desktop/) | speculative | DSO138 oscilloscope with input protection front-end. Targeted at desktop use, not Eurorack. |

These projects are **not referenced by the MACROBRUTE manual** and are
**not in the MACROBRUTE BOM**. Each spinoff has its own README explaining
what it is and what state it's in.

If you want to focus on MACROBRUTE proper, ignore this directory.
